# Albedo 1.5.4

macOS: GLB, glTF and FBX thumbnails in Finder, and corrected notes. Windows and Linux builds are unchanged.

## macOS

- Quick Look picks the extension that names a file's exact type before one that only matches a parent type. Albedo's extension lists the system identifiers for GLB, glTF and now FBX (`com.autodesk.mac.fbx`, the identifier macOS actually uses), so Finder renders them with Albedo. 1.5.3 wrongly described those formats as out of reach.
- Albedo's own types conform to `public.3d-content` again; Finder and Spotlight classify them as 3D content. 1.5.3 had dropped that conformance for no gain.
- OBJ, STL, PLY, USD and USDZ stay with Apple's own extensions, which name those types exactly. DAE stays with SceneKit.
- The release workflow renders GLB and 3MF through Quick Look on real hardware and reports an explicit SKIP on GitHub's virtual runners, which have no GPU for WebKit inside the extension sandbox.

Finder shows every Quick Look thumbnail, Apple's included, on its white rounded card; the PNG Albedo returns is transparent, as on Windows.

Verified on macOS 26 (Apple Silicon) with the 1.5.3 DMG plus these changes: GLB, FBX and 3MF through Quick Look, GLB, glTF and OBJ through the application CLI. Builds remain ad-hoc signed and are not Apple-notarized.
