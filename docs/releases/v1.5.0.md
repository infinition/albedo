# Albedo 1.5.0

Adaptive retopology and native desktop packaging for Windows, macOS and Linux.

## Retopology

- Added adaptive reconstruction using source curvature, with protected creases and boundaries.
- Added transported quad directions and matching repair, with convexity, winding and material checks.
- Fixed crease normals, relaxation safeguards, deviation overlays and exported sidecar ordering.
- Added honest budget warnings and aggregate reports. Quads remain paired triangles in GLB with an Albedo edge mask; animation-ready edge loops are not guaranteed.

## Desktop platforms

- Windows x64: portable executable, ZIP and installer with embedded Explorer thumbnail provider.
- macOS 12+: universal Intel and Apple Silicon app with a bundled Quick Look thumbnail extension.
- Linux x64: Debian/RPM packages with a WebKit thumbnail helper, plus AppImage with in-app thumbnails.
- Shared thumbnail rendering, local Draco/KTX2 decoders, native preference/cache directories, POSIX texture paths and Command shortcuts.
- Release publication waits for all platform builds and thumbnail checks to succeed.

Native thumbnail sandboxes may restrict external textures or glTF buffers. Embedded-resource formats such as GLB avoid that restriction. Linux desktop thumbnails require the native package. macOS builds are ad-hoc signed and are not Apple-notarized.

Before CI: Windows production rendering passed for GLB, external-buffer glTF and OBJ; 138 Rust tests, 4 JavaScript tests and 3 platform checks passed. Native macOS/Linux validation is performed by this release workflow. See `docs/PLATFORMS.md` and `docs/RETOPO-ADAPTIVE.md` for details and measured limits.
