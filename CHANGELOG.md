# Changelog

## 1.5.1

macOS Quick Look thumbnails work: the extension is now reached for the formats
Albedo owns, its WebKit renderer launches inside the sandbox, the page receives
its job, and the drawing fills the whole thumbnail. The release check exercises
the real Quick Look path. Windows and Linux are unchanged. See
[release notes](docs/releases/v1.5.1.md).

## 1.5.0

Adaptive reconstruction and guided quad pairing, crease-normal and sidecar fixes,
shared offline thumbnail rendering, native macOS/Linux backends, and a three-platform
release workflow with rendering checks. See [release notes](docs/releases/v1.5.0.md)
and [platform requirements](docs/PLATFORMS.md).
